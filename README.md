# 🚀 Space Adventure AutoClick

> Автоматический кликер и закрыватель рекламы для Telegram mini-app Space Adventure

## ⚠️ Статус проекта

**BETA версия** - работает нестабильно, закрывается не вся реклама. Проект в активной разработке.

## ✨ Возможности

- ✅ Автоматический клик по игровым кнопкам (Claim, Start и др.)
- ✅ Множественные методы закрытия рекламы:
  - Удаление iframe с рекламой
  - Поиск кнопок закрытия по селекторам
  - Поиск крестиков в углах экрана
  - Агрессивный клик по правому верхнему углу
- ✅ Статистика работы в реальном времени
- ✅ Автосохранение состояния
- ✅ Удобная панель логов
- ✅ Кулдауны для предотвращения спама

## 📦 Установка

### Шаг 1: Установите менеджер пользовательских скриптов

Выберите один из расширений для вашего браузера:

**Violentmonkey**
- [Chrome/Edge](https://chrome.google.com/webstore/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag)
- [Firefox](https://addons.mozilla.org/firefox/addon/violentmonkey/)

**Tampermonkey**
- [Chrome/Edge](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- [Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/)

### Шаг 2: Установите скрипт

1. Откройте файл [`space-adventure-autoclick.user.js`](space-adventure-autoclick.user.js)
2. Нажмите кнопку **"Raw"** на GitHub
3. Менеджер скриптов автоматически предложит установку
4. Нажмите **"Install"** / **"Установить"**

### Шаг 3: Запустите игру

1. Откройте Space Adventure в Telegram Web
2. Скрипт загрузится автоматически
3. Нажмите кнопку **"▶ Старт"** в панели логов внизу экрана

## 🎮 Использование

### Интерфейс

Панель логов находится внизу экрана:

```
┌─────────────────────────────────────────────────┐
│ 🚀 Pro | 👆15 | 🚫3 | ⏱5м  [▶ Старт] [🗑]     │
├─────────────────────────────────────────────────┤
│ [12:34:56] ✅ Клик: Claim                       │
│ [12:35:01] 🗑️ Удален iframe с рекламой         │
│ [12:35:15] ⏳ Кулдаун 75с                       │
└─────────────────────────────────────────────────┘
```

### Элементы управления

| Элемент | Описание |
|---------|----------|
| **▶ Старт** | Запустить/остановить автокликер |
| **🗑** | Очистить логи |
| **Клик по заголовку** | Свернуть/развернуть панель |

### Статистика

- 👆 - Всего кликов
- 🚫 - Закрыто рекламы
- ⏱ - Время работы в минутах

## ⚙️ Настройки

### Интервалы проверки

Можно изменить в коде:

```javascript
const CHECK_INTERVAL_MS = 12000; // Проверка каждые 12 секунд
```

### Кулдауны кнопок

```javascript
cooldownDuration: () => 75000 + Math.random() * 25000 // 75-100 секунд
```

### Зоны поиска крестиков

```javascript

```

## 🐛 Известные проблемы

- ⚠️ Не вся реклама закрывается автоматически
- ⚠️ Некоторые модальные окна требуют ручного закрытия
- ⚠️ Возможны ложные клики в агрессивном режиме

## 🔧 Отладка

### Логи в консоли

Откройте консоль браузера (F12) для просмотра детальных логов:

```javascript
[Space Adventure Pro] ✅ Клик: Claim
[Space Adventure Pro] 🗑️ Удален iframe с рекламой
```

### Ручное управление

В консоли браузера:

```javascript
// Остановить скрипт
stopScript();

// Запустить скрипт
startScript();

// Очистить сохраненное состояние
localStorage.removeItem('spaceAdv_running');
localStorage.removeItem('spaceAdv_stats');
```
